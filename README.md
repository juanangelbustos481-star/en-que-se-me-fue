# ¿En qué se me fue?

Aplicación web progresiva (PWA) para registrar y analizar gastos personales.

## Funciones
- Registrar, editar y eliminar gastos.
- Clasificar movimientos por categoría.
- Resumen mensual y gráfico de distribución.
- Presupuesto mensual.
- Búsqueda y filtro de movimientos.
- Exportación de gastos a CSV.
- Almacenamiento local en el navegador.
- Caché para uso básico sin conexión después de la primera visita.

## Publicar con GitHub Pages
1. Abre **Settings** en este repositorio.
2. En el menú lateral, entra en **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save** y espera a que GitHub termine la publicación.

La dirección esperada será: https://juanangelbustos481-star.github.io/en-que-se-me-fue/

## Privacidad de los datos
Los gastos y el presupuesto se guardan en el almacenamiento local del navegador. No se envían a un servidor y no se sincronizan automáticamente entre dispositivos.
